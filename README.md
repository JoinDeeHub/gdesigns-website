# 🚀 Complete Development Steps

## 1️⃣ Create React + Vite Project

```bash
npm create vite@latest gdesigns-website
```

Choose:
```bash
React
JavaScript
```

---

## 2️⃣ Move Into Project

```bash
cd gdesigns-website
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Install Tailwind CSS

```bash
npm install -D tailwindcss postcss autoprefixer
```

---

## 5️⃣ Configure Tailwind

Create:
- `tailwind.config.js`
- `postcss.config.js`

Add Tailwind imports inside:
```css
src/index.css
```

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

---

## 6️⃣ Install React Icons

```bash
npm install react-icons
```

---

## 7️⃣ Add Assets

Place all images and PDFs inside:

```bash
public/
```

Including:
- Logo
- Project Images
- Floor Plan PDF

---

## 8️⃣ Build Website UI

Implemented sections:
- Hero Section
- Navigation Bar
- About Section
- Projects Section
- Floor Plan Section
- Contact Section
- Footer

---

## 9️⃣ Add Interactive Features

Implemented:
- Smooth hover effects
- Clickable buttons
- Email redirect
- Phone call redirect
- Instagram redirect
- PDF open functionality

---

## 🔟 Run Locally

```bash
npm run dev
```

Open:
```bash
http://localhost:5173
```

# ☁️ Deployment Steps (Cloudflare)

## 1️⃣ Push Project To GitHub

```bash
git init
git add .
git commit -m "Initial Commit"
git branch -M main
git remote add origin https://github.com/JoinDeeHub/gdesigns-website.git
git push -u origin main
```

---

## 2️⃣ Connect GitHub To Cloudflare Pages

Inside Cloudflare:
- Workers & Pages
- Create Application
- Import Existing Git Repository

---

## 3️⃣ Build Configuration

Framework Preset:
```bash
React (Vite)
```

Build Command:
```bash
npm run build
```

Build Output Directory:
```bash
dist
```

---

## 4️⃣ Add Custom Domain

Connected:
```bash
gdesignsarchitectsbuilders.site
```

Updated:
- Cloudflare Nameservers
- DNS propagation
- SSL activation
